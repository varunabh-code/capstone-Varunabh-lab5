# Learnify - Online Learning Platform (Web Dev I Lab Assignment 5)

**Theme:** Online Learning Platform  
A responsive single-page website built using HTML5 and CSS3.

## Sections Included
- **Header & Navigation:** Brand logo, search bar, and navigation links.
- **Hero Section:** Main banner with tagline, search bar, and fade-up animation.
- **Popular Categories:** Grid layout displaying 8 learning categories.
- **Featured Courses:** Course cards with filter controls (Level, Price, Certificate).
- **Pricing & Testimonials:** Plan comparison cards and student reviews.
- **Contact & Footer:** Inquiry form with required fields and footer with social links.

## Layout & Breakpoints
- **Flexbox:** Used for navbar, filter bar, hero search, and footer alignment.
- **CSS Grid:** Used for categories, courses, pricing, and testimonials.
- **CSS Variables & Relative Units:** Colors defined in `:root` with `rem` and `%` units.
- **Breakpoints:**
  - `<= 768px` (`48rem`): Stacks navbar/footer and converts grids to single-column.
  - `<= 480px` (`30rem`): Stacks hero search bar and filter controls for mobile screens.

## How to Run
1. Download or clone the repository.
2. Open `index.html` in any web browser.
